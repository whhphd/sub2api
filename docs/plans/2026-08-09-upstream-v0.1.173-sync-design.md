# Upstream v0.1.173 Sync Design

## Scope

Merge `upstream/main` at v0.1.173 into the CallAI fork, preserve the existing
OpenAI OAuth customizations, run the complete local validation suite, push the
fork, build a production image, and deploy it to `sub2api-ovh`.

The balance overdraft policy is explicitly out of scope for this sync. It will
remain unchanged unless handled as a separate task.

## Integration Rules

- Use a merge commit and retain the pre-sync backup branch for rollback.
- Preserve the OAuth noop tool-call injection, configurable OAuth 429 streak
  threshold, new-account default switches, OAuth 403 transient scheduling
  behavior, and both local input-token fallback paths.
- Resolve generated Wire output by regenerating it after provider changes.
- Combine the custom settings controls with upstream Channel Monitor V2,
  Grok, and email-domain registration settings.
- Keep upstream migrations by full filename. Existing custom migrations 194 and
  195 coexist with upstream migrations using the same numeric prefix because
  the migration ledger keys on filename.
- Upstream Channel Monitor V2 remains opt-in through its existing v1 default.

## Verification

- Audit all files changed by both branches before resolving conflicts.
- Run targeted backend tests for OAuth injection, 429/403 scheduling, input-token
  handling, billing, and upstream additions.
- Run affected backend packages, frontend tests, and the production frontend
  build.
- Before deployment, back up the Compose file and schema state; do not restart
  PostgreSQL or Redis.
- After deployment, verify migration ledger entries, new tables/indexes,
  container health, `/health` on both public domains, homepage, unauthenticated
  admin rejection, and zero application restarts.

## Rollback

Keep the existing production image tag available and restore the Compose image
tag if the new container fails health checks or startup migrations. New additive
schema objects are retained during an image rollback because the old image does
not depend on them.
